# 视频合成

把分镜图变成可用的镜头，再按顺序整理成一支短片。整条链路都在画布上完成：图片节点提供画面，视频生成节点产出镜头，素材库负责归档。

## 一条可复现的合成路径

1. **备好分镜**：先用文本节点写清镜头描述，用图片生成节点产出每个镜头的画面，或用 3D 导演台导出构图参考图。
2. **逐镜头生成视频**：把画面连到“视频生成”节点，选择支持图片参考的视频模型，按镜头写运镜与动作描述，逐个生成。
3. **检查运动**：在节点中播放，逐条确认镜头运动是否自然；不理想就改提示词重生成，或用“创建副本”保留旧结果对比。
4. **归档与导出**：满意的镜头“保存到素材库”，再在节点上点击下载图标导出成片素材。

::: tip 生成设置怎么选
打开视频生成节点下方的生成设置，按模型支持的能力选择图片参考模式、时长、分辨率与比例。参考素材、时长、分辨率和音频能力都取决于所选模型与供应商。
:::

## 对话也可以是 Agent

右侧对话框可以直接驱动合成流程：描述你要的成片，Agent 会拆解分镜、准备素材、串联节点，再按你的确认推进。适合一次说清整支短片的需求，细节再逐个镜头微调。具体用法见 [Agent 助手](./agent.md)。

## 常见问题

**生成的视频没有声音？**

音频能力由所选模型与供应商决定，生成设置中允许开启音频时才可能带声音。也可以单独生成音频节点，在后续剪辑中合成。

**镜头之间风格不统一？**

固定同一套参考图与文本描述，只改变运镜与动作部分；换模型或换提示词风格会让前后镜头差异变大。
